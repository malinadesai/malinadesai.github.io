JWST: pulled via astroquery.mast.Observations. “Available” = proposal has at least one executed, calibrated exposure (calib_level ≠ −1). “Scheduled” = proposal is approved and visible in MAST but has not yet been observed. Links go to STScI's public jwst-program-info pages.
Chandra: pulled via astroquery.heasarc against the chanmaster catalog. Calibration-only exposures are excluded. “Available” = status archived. “Scheduled” = approved but unobserved/untriggered (e.g. a target-of-opportunity awaiting an outburst). There's no stable public deep link per ObsID, so program entries link to SIMBAD for the named target; browse the raw data at the Chandra Data Archive.
